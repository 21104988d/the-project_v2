## Download Instructions

1. **Visit https://cryptologos.cc/**
2. **Search for each cryptocurrency/token by name**
3. **Download the PNG version (usually 200x200px or higher)**
4. **Rename the file to match the exact filename listed above**
5. **Place in this `/public/icons/` directory**

## Image Requirements

- **Format:** PNG with transparent background preferred
- **Size:** Minimum 128x128px, recommended 256x256px or 512x512px
- **Quality:** High resolution for retina displays
- **Naming:** Exact match to the filenames listed above (lowercase, no spaces)

## Fallback Options

If an icon is not available on cryptologos.cc:
1. Check the official project website
2. Look for brand kits or press resources
3. Search for high-quality logos on GitHub repositories
4. Use placeholder icons temporarily and update later

## Custom Logo

For `logo.png`, create a custom logo for "The Project" that:
- Represents cross-chain bridging or connectivity
- Uses your brand colors (brand-primary: #3b82f6, brand-secondary: #10b981)
- Works well on both light and dark backgrounds
- Is recognizable at small sizes (32x32px)

## Testing

After adding icons, test that they display correctly by:
1. Running `npx vite` in development
2. Checking the browser console for 404 errors
3. Verifying icons appear in all components
4. Testing on both desktop and mobile viewports
